# Tu Saldo — prototipo interactivo

Demostración de una app de recargas móviles para Venezuela, presentada dentro de un marco de iPhone. Todas las operaciones son simuladas.

- Nivel 2: recargas de Bs 1.000, Bs 1.500 o Bs 2.000.
- Hasta 6 recargas por mes.
- Pago completo del período el 15 y el 30 de cada mes.
- Registro, inicio, niveles, perfil y cierre de sesión.

El prototipo es un archivo HTML autónomo. No requiere servidor, instalación ni claves de API.
